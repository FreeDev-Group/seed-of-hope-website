Site features for Seed of Hope / Semence d'Espoir that must not depend on the theme.

== Description ==

* Settings > Reading > "Impact figures": makes the impact figures pattern available. Off by default — enable it
  only when Seed of Hope has confirmed real figures.
* Uploaded JPEG and PNG images get WebP sub-sizes (lighter pages on mobile connections).
* Removes the emoji detection script.

Future content types (for example a "Programme" type, see docs/decisions.md ADR-006) belong in this plugin.
